# FrontierDock — 前沿工作站

**Build your own research frontier.**

An open-source, self-hosted research intelligence platform.

FrontierDock 把研究者日常反复做的几件事放到一个页面里。查看期刊更新，按卷期浏览文章，读摘要，把感兴趣的论文放进待读清单，再看看自己的资料集中在哪些领域和关键词。数据保存在自己的工作区，页面可以在本机浏览器打开。

初次使用时，用户可以让自己的 Agent 陪着配置。先聊研究方向，再选择关注的期刊、语言和年份。愿意用 API 的人可以接入检索、翻译和 PDF 提取服务，也可以让已有 Agent 完成搜索与翻译，先从不需要密钥的方式开始。配置可以修改，页面也可以继续改。

目前提供研究工作台、期刊与卷期目录、题录检索、摘要阅读、阅读状态和资料统计。深绿色侧栏、米纸阅读主题与简洁卡片构成统一界面。高频关键词按年份查看，统计来自实际库存，不代表整个学科的研究热度。

维护流程区分来源题录、网页线索和模型生成内容。Search 返回的摘要只用来帮助找页面，不能当作作者原始 Abstract。原摘要不足时需要核对出版社页面；译文与关键词绑定来源指纹。身份冲突保留原记录，卷期未知时保留未知。

基础运行使用 Python 标准库与 SQLite，无需前端构建。DeepSeek、兼容模型 API 和 MinerU 都是可选接入。定时计划采用每刊检查间隔，实际自动运行需要用户选择并配置外部调度。Agent 模式生成的队列，需要有工具能力的 Agent 真正执行。

遇到配置、网络或程序问题，用户可以先请自己的 Agent 协助定位和修复。无法解决的可复现缺陷，再整理成脱敏报告交给维护者。这个项目希望让用户拥有可以持续改造的研究工具，也让日常使用中的小调整更容易自己完成。
